# Antrean Bank

program C++ yang mensimulasikan alur antrean teller di bank berdasarkan waktu dipanggilnya

## Case
case asli berasal dari link berikut: https://atcoder.jp/contests/abc294/tasks/abc294_d?lang=en 

di kasus tersebut terdapat 3 event:
1. customer dipanggil untuk pertama kalinya
2. customer mendatangi teller untuk dilayani
3. customer dipanggil kembali apabila belum mendatangi teller

## Build and Run and Install
1. buat folder build dan jalankan cmake
2. run dengan ./ban_app
3. program bisa di install ke sistem
